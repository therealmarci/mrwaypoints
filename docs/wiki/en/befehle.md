# Commands

In game nearly everything goes through the menu `/waypoints`.

| Command | What it does | Permission |
|---|---|---|
| `/waypoints` (`/waypoint`, `/wegpunkte`, `/wegpunkt`, `/wps`) | [Menu](menue.md) with all waypoints | `mrwaypoints.use` |
| `/waypoints stop` | End the guide | `mrwaypoints.use` |
| `/mrwaypoints reload` | Reload config, categories and messages | `mrwaypoints.admin.reload` |
| `/mrwaypoints discord [test]` | Status of the Discord log · send a test message | `mrwaypoints.admin.discord` |
| `/mrwaypoints version` | Version and update status | `mrwaypoints.version` |

Teleporting works in the menu with a **shift click** on a waypoint (`mrwaypoints.teleport`).
